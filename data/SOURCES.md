# Data sources and honesty note

All evidence text is hand-written fictional material. Scenarios follow common patterns documented in public
forensic training material (e.g. OTRF Security-Datasets, NIST CFReDS, Digital Corpora) but no text, log line or file
is copied from them. Licences of those projects still need to be read before the report cites them as inspiration.

- Names, companies and mailboxes are invented. Domains use `.test` / `.example`; IP addresses use documentation ranges (RFC 5737).
- Tool names are real (Autopsy, Volatility 3, Wireshark, Plaso, YARA, ExifTool); the version numbers are plausible and must be confirmed before the viva.
- SHA-256 values are derived from the evidence title, not from real files.
- The demo password is public by design. Change it for anything beyond local testing.
